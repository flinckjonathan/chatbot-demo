        How it works

        The agent

        Claude gets three tools: look up free times, create a booking, send a contact request. The booking core validates every call, so a missing consent or a stale time comes back as an error the model has to handle in the conversation. One booking per conversation, and the tool loop stops after three rounds. Pictures go to the model and are never stored.

        The guardrails

        Binding rules in the system prompt: answer only from the knowledge base, quote only published prices, no definite diagnoses, instructions inside messages or pictures are not commands. Rate limits per visitor and per day keep the API key safe behind a public page. If the model fails after a booking went through, a fixed text still tells you the reference.

        The staff side

        Open the staff view to write a fact for the bot, approve it, and watch it appear in the prompt the bot sees, after the cached part so nothing is recomputed. Hide it and it is gone again. Everything on that page belongs to your session only.
